# Sesión 01: Bienvenida — Ciencia de Datos, Python y Markdown en Google Colab

![Bienvenida al curso](Saludo_Bienvenida.png)

La sesión usa `Sesion_01_Ciencia_de_datos.ipynb`, que integra el recorrido conceptual, el microanálisis y la guía práctica de Markdown. `bienvenida_saludo_acuerdos.md` contiene la apertura y los acuerdos del curso.

## 🎯 Objetivo de la Sesión

Que el estudiante entienda qué es la ciencia de datos, reconozca Big Data y sus 7 V, conozca el ciclo CRISP-DM, comprenda el papel de Python y use Google Colab y Markdown para ejecutar y documentar un primer análisis.

## 📚 Contenido Conceptual

1. **¿Qué es la Ciencia de Datos?** Definición, por qué es necesaria cuando los problemas son muy complejos para reglas explícitas. Ejemplos de aplicación en supervisado (spam, diagnóstico médico, fraude) y no supervisado (segmentación, detección de anomalías).
2. **Big Data y las 7 V:** volumen, velocidad, variedad, veracidad, valor, variabilidad y visualización.
3. **CRISP-DM**: Comprensión del negocio → Comprensión de los datos → Preparación de datos → Modelado → Evaluación → Despliegue.
4. **Tipos de aprendizaje:** supervisado, no supervisado y por refuerzo.
5. **Python y Google Colab:** entorno de trabajo, ejecución ordenada y alternativa local con Visual Studio Code.
6. **Markdown:** narrativa, sintaxis, fórmulas, enlaces, imágenes, bloques de código, plantilla y lista de verificación.

### Recorrido real de los notebooks

- `Sesion_01_Ciencia_de_datos.ipynb`: problema de negocio, Big Data y 7 V, CRISP-DM, tipos de aprendizaje, Python, Colab, microanálisis y taller guiado de Markdown.
- La guía integrada cubre encabezados, listas, tablas, formato, código, enlaces, imágenes, HTML y buenas prácticas.
- El laboratorio separa pregunta, datos, cálculo e interpretación; compara promedio, extremos y rango mediante celdas cortas.

## 🏆 Actividad de Cierre

- Cada estudiante crea su primer notebook en Colab.
- Escribe una celda de Markdown con: un título (`#`), un objetivo personal del curso (lista), y una tabla con 3 temas que más le interesan de la ruta.
- Ejecuta una celda de código con un simple `print("Hola, ciencia de datos")`.
- Ejecuta el microanálisis y explica qué permite y qué no permite concluir el promedio.

## ✅ Criterios de Evaluación

- Participación y creación exitosa del primer notebook en Colab.
- La celda de Markdown usa correctamente al menos 3 elementos de sintaxis distintos (título, lista, tabla, negrita, etc.).
- Explicación correcta de las 7 V mediante ejemplos.
- Conclusión del microanálisis separando resultado, interpretación y limitación.
